EdgeOne Proxy

基于腾讯云 EdgeOne 边缘函数的 GitHub / Docker 镜像代理。把下面命令里的 当前域名 换成你的部署域名即可。

GitHub

克隆仓库、下载 Release、读取 raw / API 文件。

git clone https://HOST/gh/user/repo.git
curl -O https://HOST/gh/user/repo/releases/download/v1.0.0/app.zip
curl https://HOST/raw/user/repo/main/README.md
curl https://HOST/api/repos/user/repo

等价写法：gh = github.com，raw = raw.githubusercontent.com，api = api.github.com，codeload、gist、gistraw 同理；也可以直接写 /github.com/user/repo。

Docker Hub

把本域名配成镜像加速器，之后 docker pull nginx 自动走这里。编辑 /etc/docker/daemon.json：

{
  "registry-mirrors": ["https://HOST"]
}
sudo systemctl restart docker

部分面板 / 环境不支持多镜像时，也可以直接拉取：

docker pull HOST/library/nginx:latest

其他镜像仓库

GHCR、GCR、Quay、registry.k8s.io 走路径前缀方式拉取（镜像名里多一层仓库别名）：

docker pull HOST/ghcr/owner/image:tag
docker pull HOST/gcr/google-containers/pause:3.9
docker pull HOST/k8s/pause:3.9

支持的主机

github.comapi.github.comraw.githubusercontent.com codeload.github.comobjects.githubusercontent.com gist.github.comgist.githubusercontent.com github.githubassets.commedia.githubusercontent.com registry-1.docker.ioauth.docker.io ghcr.iogcr.ioquay.ioregistry.k8s.io

限制

EdgeOne 边缘函数的请求体上限是 1MB，所以只支持拉取。docker push 和较大的 git push 会失败；私有仓库的鉴权头会原样转发，但登录态 Cookie 不在本代理的用途范围内。
